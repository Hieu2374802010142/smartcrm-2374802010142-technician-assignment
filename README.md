# SmartCRM - Technician Assignment

## Luồng nghiệp vụ
L04 - Phân công kỹ thuật viên và lịch hẹn

## Phạm vi
Quản lý trung tâm xem các phiếu bảo hành chưa được phân công,
chọn kỹ thuật viên phù hợp và đặt lịch hẹn giao - nhận máy cho khách hàng.
Hệ thống kiểm tra trùng lịch trước khi lưu thông tin phân công và lịch hẹn.

## Chức năng dự kiến
1. Xem phiếu chưa phân công
2. Xem thông tin kỹ thuật viên
3. Phân công kỹ thuật viên
4. Đặt lịch hẹn
5. Kiểm tra trùng lịch
6. Kỹ thuật viên xem công việc

## Công nghệ
- Frontend: HTML, CSS
- Backend: Python 3.12, FastAPI
- Database: SQLite
- Design: Figma
- Database Design: dbdiagram.io
- Diagram: Draw.io
